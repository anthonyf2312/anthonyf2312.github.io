How to send something

Open an issue on the repository this site is built from. You will need a GitHub account; nothing else is required.

Open an issue →

If you would rather not use GitHub, the pages themselves are plain files in that same repository, so a pull request works too.

What helps most

In rough order of usefulness:

  1. A number you have checked in the game. Most figures here came from a community wiki that has not kept pace with balance patches. A stat you have read off your own screen beats anything else on this page.
  2. A unit, hero or mode that is missing. New content arrives in events as often as in version updates, and event releases are easy to miss.
  3. Something that reads as current but is not. Whole systems have been replaced — the Clan Tournament became the Clan War, items became perks — and a page can describe a mode that no longer exists without looking wrong.
  4. Plain-English fixes. If a sentence assumes you already know the jargon, it has failed at the one job this site has.

What to include

Enough that it can be checked without guessing:

  • Which page, and which unit or section.
  • What it says now, and what it should say.
  • Where you saw the correct version — in-game, a patch note, or a screenshot.

A screenshot of the in-game text is the strongest thing you can attach, because it settles the question outright.

What this site is not

It is an unofficial reference, not a support channel. Bug reports, account problems and refunds all have to go to the developers — nothing sent here reaches them.

It also does not publish figures nobody has verified. If a number cannot be confirmed, the entry says so or leaves it out, rather than guessing at it.
