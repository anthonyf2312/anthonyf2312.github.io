TESSELDISCORD BOT

MODULES

Tessel is a Discord bot with no features of its own. You add the ones you want, one server at a time — moderation here, levelling there, nothing shared between them. Modules tile together; that's the whole idea.

install/module install <url>

turn on/module load <name>

Approve what it's allowed to do, and its commands appear. In your server only. No restart.

Reviewed and unreviewed

Reviewed means someone read the code at a specific commit and signed it. Change one byte afterwards and the signature stops matching, so it can't be inherited by code nobody looked at.

Unreviewed means exactly that. Tessel will still install it — you'll get a warning first, because an unreviewed module can do anything the permissions it asks for allow.

Either way, modules run locked away from the bot's token, its database and the filesystem. What they can do is the permission list on each tile, and you approve that before anything runs.
