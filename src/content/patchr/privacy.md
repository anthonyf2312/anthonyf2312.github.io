# Privacy Policy

Last updated: 28 September 2026

This policy covers the public Patchr bot and its website, both run by Anthony ([@anthonyf2312](https://github.com/anthonyf2312)), an individual in the United Kingdom. Anthony is the controller of the data described here. If you use a copy of Patchr that someone else runs, that person is responsible for it.

## What Patchr stores

Patchr stores only what it needs to post patch notes:

- **Server settings:** your server's ID, the default channel and ping role you chose, whether posts are published in announcement channels, and whether posts show a thumbnail.
- **Feeds:** which GitHub repositories your server follows, the channel and ping role for each, and the Discord user ID of the person who set it up.
- **Posts:** for each message Patchr posts, the channel and message IDs and a copy of the note it showed. For notes written with `/patch`, that includes the text, and the Discord user ID and display name of the person who wrote it. Patchr keeps this so posts can be edited later and are never posted twice.
- **Drafts:** a note in its private `/patch` preview, with the Discord user ID of the person writing it. A draft is deleted when you post or cancel it, or within about 25 minutes otherwise.
- **GitHub repositories:** the public name, ID and owner avatar of each repository that any server follows.
- **Logs:** short technical logs of errors, with server IDs but never message content.

Patchr does not read your server's messages, member list or direct messages. It doesn't ask Discord for any of the privileged intents that would allow that.

## Why, and on what basis

Only to run Patchr: to post notes in the channels you chose, to keep those posts up to date, and to keep the service working. Nothing is sold, shared for advertising, or used to build profiles.

Under UK data protection law, the basis is legitimate interests: a server's admins added Patchr to post patch notes, and it can't do that without this data. You can object at any time (see below).

## Where it's kept

On a server Anthony runs at home in the United Kingdom.

## Third parties

- **Discord** delivers the messages. See [Discord's privacy policy](https://discord.com/privacy).
- **GitHub** is where Patchr reads public release information. Patchr only reads public repositories. See [GitHub's privacy statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).

Both are companies based in the United States. They handle your data under their own policies, not this one.

## The website

Patchr's website is hosted on GitHub Pages. It has no cookies, no analytics, no tracking and no embedded content, and it doesn't ask you for anything. If you use its light/dark switch, your choice is kept in your own browser so the site remembers it, and never leaves your device. GitHub records visitors' IP addresses for security, under [GitHub's privacy statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement). Anthony doesn't see or receive that data.

## How long it's kept, and deleting it

When Patchr is removed from a server, everything it stored for that server is deleted: settings, feeds, post records and drafts. If Patchr was offline at the time, the data is deleted the next time it starts. Messages Patchr already posted stay in your channels until you delete them.

## Your rights

You can ask for a copy of the data Patchr holds about you, and ask for it to be corrected, deleted, or restricted. You can also object to its use, or ask for it in a portable format. To do any of these, open an issue at [github.com/anthonyf2312/patchr/issues](https://github.com/anthonyf2312/patchr/issues) or ask in the [support server](https://discord.gg/hsWvqgs9eG). For anything you'd rather not post publicly, use the repository's [private reporting form](https://github.com/anthonyf2312/patchr/security/advisories/new). You'll get an answer within a month.

If you're unhappy with how your data is handled, you can complain to the UK's Information Commissioner's Office at [ico.org.uk](https://ico.org.uk/make-a-complaint/).

## Age

Patchr works inside Discord, so you need to meet Discord's minimum age to use it.
